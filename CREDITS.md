## Notes on this collection

1. **The 832 Composio MCP stubs were excluded.** `ComposioHQ/awesome-claude-skills` contains a
   `composio-skills/` directory with 832 auto-generated `<app>-automation` skills — near-identical
   40-line templates, one per SaaS app, all requiring the Rube MCP server. They were skipped to keep
   this collection browsable. See `_LICENSES/ComposioHQ_awesome-claude-skills.txt` and the repo if you want them.

2. **Duplicates resolved in favour of the Anthropic original.** ComposioHQ re-hosts several Anthropic
   skills. For five of them (`canvas-design`, `brand-guidelines`, `internal-comms`, `theme-factory`,
   `webapp-testing`) every skill file was verified byte-identical to Anthropic's and the copy was dropped
   — the *only* difference was `LICENSE.txt`, where Composio ships Apache 2.0 over content Anthropic
   licenses under its own proprietary terms. The version kept here is Anthropic's, carrying Anthropic's
   license. If you need those five under Apache 2.0, take them from the ComposioHQ repository instead.
   Where the skill content genuinely differs, both versions are kept and the Composio one is suffixed
   **(Composio fork)**.

3. **Anthropic skills are not open source.** Each carries `© 2025 Anthropic, PBC. All rights reserved.`
   and its own `LICENSE.txt` governing use under your agreement with Anthropic. They are *not* MIT/Apache.

4. **`avoid-ai-writing` internal duplicates removed.** That repo ships the same skill three times
   (repo root, `skills/`, `plugins/`). Only the complete `skills/` versions are kept.

5. Repository scaffolding (`.git`, `.github`, CI, tests, top-level READMEs) was not copied — only the
   skill folders themselves, plus their `references/`, `scripts/` and `assets/` subfolders.
